# Homebrew tap

```
brew install --cask rohit-saluja/tap/wombit
brew install rohit-saluja/tap/wombit-cli
```

`Casks/wombit.rb` installs [Wombit](https://wombit.app), a Mac app that explains what is using the
disk and clears it safely, and `Formula/wombit-cli.rb` its open command-line tool. Both are written
by the app's release pipeline; please don't edit them here.
