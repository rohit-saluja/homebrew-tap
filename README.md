# Homebrew tap

```
brew install --cask rohit-saluja/tap/filemanager
brew install rohit-saluja/tap/filemanager-cli
```

`Casks/filemanager.rb` installs the Filemanager app (a Mac storage app; the name is a
placeholder) and `Formula/filemanager-cli.rb` its open command-line tool. Both are written by the
app's release pipeline; please don't edit them here.
